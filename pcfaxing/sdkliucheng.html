SDK 在线验权与 7 天离线启动流程

适用于基础单机游戏。首次在线验权后签发设备离线许可；许可有效时可离线启动。运行中发生撤权或登录替换时，只限制后续启动。

关键名词

Launch Ticket
在线启动使用的一次性短期凭证。
Offline License
离线许可。在线验权成功后签发，允许匹配设备在 168 小时内离线启动。
DLC AppID
SDK 查询 DLC 使用权的统一标识。
Session Ticket
游戏具备安全服务端时使用的可选增强票据。

确认口径

基础单机游戏不需要自建服务端。macOS 平台客户端通过 Wine 通信桥接与 Windows x86_64 游戏 SDK 协作，并由 SDK 与平台启动鉴权服务完成游戏本体和 DLC 验权；只有联机资格、交易物品或高价值奖励需要额外保护时，游戏才接入 Session Ticket。

离线窗口从最近一次服务端成功验权开始计算 168 小时；再次成功复核后才能续期。
撤权处理游戏本体被撤权或旧设备登录失效时，当前游戏继续运行；后续不再允许启动或续期。
DLC 标识SDK 统一使用 DLC AppID；文件系统继续使用 Content ID 和 Depot ID。
首发交付P0 平台为 macOS，游戏侧交付 Wine 内 Windows x86_64 通用 SDK DLL 与通信桥接。

启动入口与登录状态处理

SDK DLL 被操作系统加载，不代表玩家已经通过平台验权。直接双击 EXE 时，当前进程不得自行取得账号访问凭证，必须转回 macOS 平台客户端完成受控启动。

当前已运行游戏

SDK 不结束游戏进程、不自动重新登录，也不切换存档所属账号。玩家正常结束游戏时，由游戏保存并退出。

DLC 状态变化

SDK 单独通知游戏

SDK 返回 DLC AppID 及变化前后的“已拥有”状态。角色、关卡、地图、菜单和存档兼容由游戏研发处理；SDK 不删除角色，也不修改存档。

旧设备处于离线状态时，无法实时收到撤权或登录替换通知。限制可以延迟到设备恢复联网，或离线许可到期后生效。这是 7 天离线体验的明确边界。

场景本次新启动已经运行的游戏

可写入 SDK PRD 的补充说明

启动授权规则 1. 玩家可以从 macOS 平台客户端启动游戏，也可能直接双击 Wine 环境中的游戏 EXE。 2. 直接双击 EXE 时，SDK 发现缺少平台启动上下文，通过 Wine 通信桥接拉起平台客户端；当前进程不进入游戏，由客户端完成检查后重新受控启动。 3. 客户端已有有效在线登录状态时，使用账号访问凭证查询游戏使用权；没有在线登录状态但可以联网时，必须先提示登录。 4. 登录成功后先取得账号访问凭证，再检查游戏本体与 DLC 使用权、Build、设备和平台限制；全部通过后才能签发 Launch Ticket。 5. 账号访问凭证只由 macOS 平台客户端持有，不传入 Windows 游戏 SDK。SDK 不得仅凭 User ID 请求平台授权。 6. 无法联网时，客户端读取本机离线账号身份和 Offline License。离线许可有效时传递离线启动上下文；缺失、过期或设备不匹配时提示联网登录。 7. 在线启动时，SDK 兑换一次性 Launch Ticket，平台原子消费 nonce、创建 Platform Session ID，并签发或续期 168 小时 Offline License。 8. 平台明确返回无使用权、登录替换、Build 禁用或账号限制时，不能使用旧 Offline License 回退启动。 9. 游戏目录或 Wine 前缀复制到另一台设备后，离线许可不能通过设备绑定；玩家必须在新设备重新登录并校验使用权和文件。 10. 设备持续离线期间无法实时获知其他设备触发的退款或撤权，允许延迟至恢复联网或离线许可到期后限制下一次启动。 11. SDK 使用 Base AppID 初始化，并按 DLC AppID 返回使用权；Content ID、Depot ID 和 Manifest ID 留在文件系统。 12. 游戏本体被撤权、登录被替换或离线许可在运行中到期时，只限制后续启动和续期，不强退当前游戏。 13. 基础单机游戏不要求自建安全服务端；Session Ticket 仅作为联机或高价值权益的可选增强能力。
