SDK 在线验权与 7 天离线启动流程

适用于基础单机游戏。首次在线验权后签发设备离线许可；许可有效时可离线启动。运行中发生撤权或登录替换时，只限制后续启动。

确认口径

基础单机游戏不需要自建服务端。SDK 与平台启动鉴权服务完成游戏本体和 DLC 验权；只有联机资格、交易物品或高价值奖励需要额外保护时，游戏才接入 Session Ticket。

离线窗口从最近一次服务端成功验权开始计算 168 小时；再次成功复核后才能续期。
撤权处理游戏本体被撤权或旧设备登录失效时，当前游戏继续运行；后续不再允许启动或续期。
DLC 标识SDK 统一使用 DLC AppID；文件系统继续使用 Content ID 和 Depot ID。
首发交付P0 提供通用原生接口和 macOS 版本；Windows 待确认，专用引擎插件按试点需求评估。

当前已运行游戏

保持原平台用户 ID 并继续运行

SDK 不结束游戏进程、不自动重新登录，也不切换存档所属账号。玩家正常结束游戏时，由游戏保存并退出。

↓
DLC 状态变化

SDK 单独通知游戏

SDK 返回 DLC AppID 及变化前后的“已拥有”状态。角色、关卡、地图、菜单和存档兼容由游戏研发处理；SDK 不删除角色，也不修改存档。

旧设备处于离线状态时，无法实时收到撤权或登录替换通知。限制可以延迟到设备恢复联网，或离线许可到期后生效。这是 7 天离线体验的明确边界。

可写入 SDK PRD 的补充说明

启动授权规则 1. 玩家通过 PC 客户端启动游戏。正常启动不要求每次选择 DLC；DLC 的安装和启用状态在游戏属性中管理。 2. 在线时，客户端申请一次性启动凭证。平台复核登录状态、游戏本体与 DLC 使用权、构建版本、发布分支、设备和账号限制；SDK 兑换启动凭证并建立游戏会话。 3. 在线验权成功后，平台向当前用户、Base AppID 和设备签发离线许可。许可有效期从成功复核时间开始计算 168 小时；再次成功复核后才能续期。 4. 网络或平台启动鉴权服务不可用时，SDK 可以验证本机有效的离线许可并启动游戏。已明确无使用权、登录失效、签名错误或构建版本禁用时，不能继续使用旧许可。 5. 游戏使用 Base AppID 初始化 SDK，并按 DLC AppID 查询“已拥有”状态。Content ID、Depot ID 和 Manifest ID 属于文件系统，由平台维护映射。 6. “已安装”和“已启用”状态由 PC 客户端提供，不能作为服务端已经确认使用权的证明。游戏只加载“已拥有、已安装、已启用”三个条件都满足的 DLC。 7. 游戏本体被撤权、旧设备登录失效，或离线许可在运行中自然到期时，只限制后续启动和续期。当前已运行游戏不强退，也不切换平台用户 ID。 8. DLC 使用权变化由 SDK 通知游戏。角色、地图、入口和存档兼容由游戏研发处理。 9. 基础单机游戏不要求自建安全服务端。Session Ticket 仅作为具备联机或高价值权益游戏的可选增强能力。 10. P0 交付通用原生接口和 macOS SDK。Windows 是否同期交付待业务确认；Unity 和 Unreal 专用插件按试点需求评估。
